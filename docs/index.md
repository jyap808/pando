# Pando Keyboard

![Pando case](assets/images/case-photo.jpg)

Pando is a wired 58 key column-staggered split keyboard.

It uses an integrated MCU design on the STM32 platform with an IO expander on the secondary half of the keyboard.

Pando utilizes the same key layout as the [Pando58](https://jyap808.github.io/pando58). The core difference is that the Pando58 keyboard was designed as a DIY kit (with external controllers) while Pando is designed as an assembled PCB. This allows for a cleaner and more cohesive design.

!!! tip "Buy Pando"
    Pando comes as a pre-assembled kit on [Etsy](https://www.etsy.com/listing/4567044197/). Just provide your own keycaps and switches. Your support helps me keep this project open-source and encourages the development of new models!
